# ESQ Terminal

Интерфейс опубликован из основной ветки `main` через GitHub Pages.

Файлы интерфейса находятся в корне репозитория. `esq-terminal-source.zip` содержит полный исходный проект с сервером и тестами.

Сервер Gemini и инструментов ESQ: https://esq-terminal.katerisha.chatgpt.site
Ключ Gemini хранится только на сервере. GitHub Pages обслуживает интерфейс, серверные операции выполняет указанный сервер.

Поддерживается гостевой режим. История хранится в браузере устройства; она не синхронизируется между устройствами. Отдельный вход через Google OAuth в этой версии не реализован.
